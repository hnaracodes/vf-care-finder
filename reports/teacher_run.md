# Teacher labels, recipe v0.2 (WP3 part 3)

Generated by `scripts/wp3_teacher.py` on 2026-11-22. Numbers come from `labels/teacher_scores.json`.

## Result

- The teacher (claude-haiku-5-5) does not clearly beat the v0.2 regex on the gold set: macro F1 0.89 (0.87 to 0.91) against 0.89 for the regex, over the 24 evidence tags and 777 gold texts. Paired difference, 95% interval: -0.024 to +0.021.
- Per tag, the teacher is clearly better on 3 tags (ob_delivery, ventilator, burns) and clearly worse on 3 (anesthesia, emergency, ccu); the rest are within noise.
- Weakest teacher tags: `neurosurgery` 0.62, `ob_delivery` 0.67, `radiotherapy` 0.77.
- 29,300 distinct non-gold fact texts labeled into `labels/teacher_facts.parquet` for WP4.
- Total spend: $0.5499 over 756 API calls (budget $30 for the project, cap $10 for this run).
- Caveat: the gold set is agent-labeled and over-samples regex hits and near misses, so these are not population rates. The regex was written by reading silver facts; the teacher's prompt examples are silver facts too. Neither saw the gold labels.

## Setup

- Model `claude-haiku-5-5`, effort `low` with adaptive thinking (the model default), structured outputs (JSON schema whose tag field is an enum of the 31 tags), 40 facts per request with integer ids, max_tokens 8000.
- No temperature setting: on claude-haiku-5-5 any non-default `temperature` returns HTTP 400. Repeatability comes from the disk cache instead: every answer is stored, so reruns make no calls and give identical labels.
- Prompt `p2` (sha256 `44665b502a01396d`): `TAG_DEFINITIONS` and `TAGGING_RULES` from `src/vf/recipes.py`, a short note on overlapping tags, and 70 hand-labeled examples (at least two per tag), all silver facts outside the gold set (checked on every run). The system prompt is marked for prompt caching.
- Cache: `data/labels/teacher_cache/p2/`, one JSON file per response; the key is (recipe version, prompt version, text_norm). Ledger: `data/labels/teacher_cache/spend.jsonl`.
- Synchronous Messages API with 8 parallel requests, not the Message Batches API. Batches cost 50% less, but the whole run cost $0.55, so batching would have saved about $0.27, while synchronous calls let the script check the budget before every request and finish in minutes instead of up to an hour.

## Spend

Total $0.5499, summed over every response in the ledger (spot checks, the discarded p1 prompt, gold, training texts, retries). The ledger covers this script only; LLM calls made by other work packages are not in it. Each response's cost is computed from its `usage` block:

```
cost = (input_tokens * 0.1 + cache_creation_input_tokens * 0.125
```

`hit`: every v0.2 regex hit with a tag other than emergency, h24 and ob_delivery. `hit_common_only`: a random 2,000 of the hits that carry only those three tags (there are about 10,000; taking all would push the total past 30,000). Near misses: up to 150 texts per tag that match a loose keyword pattern (`NEAR_MISS`) but get no regex tag. `random`: 2,000 uniform from the rest. Gold texts are excluded. 0 single texts failed (refusal or bad output) and are left out.

## Spot check (50 labels read by hand before scaling)

Sample: 20 regex hits, 15 near misses, 5 common-only hits, 10 random (spot_sample, seed fixed).

- Prompt p1: Dropped emergency on 3 of the 4 trauma facts although the emergency definition covers trauma ('major trauma care center in kerala' -> trauma, location). Added location to 3 service facts that only mention a place ('has a modern pet-ct department at paras hospital gurgaon' -> ct, location). Tagged neurosurgery for 'trauma and neuro-icu infrastructure'. Prompt p2 adds a short overlap note (trauma comes with emergency, ccu with icu, a neuro ICU is an icu) and narrows location; the definitions and rules are unchanged.
- Prompt p2: Evidence tags agree with the agent's reading on 48 of 50 facts. The two misses are borderline: 'english-speaking staff with experience in holiday dialysis' (teacher none, agent dialysis) and 'patient monitoring equipment visible in ward/icu images' (teacher photo_artifact only, agent icu and photo_artifact). Noise tags: 2 doubtful other_clinical ('manufactures middle ear implants and hearing aids', 'implements energy-saving and waste-reducing methods'). The p1 problems above are fixed on these 50. Judged good enough to label at scale.

## Limits

- Gold is agent-labeled, by four labelers for the v0.2 rows; the teacher is scored against another model's reading of the same definitions, not a clinician's.
- Teacher labels are noisy targets. WP4 should ship a student only if it beats the regex per tag on gold.
- Prompt p2 was revised once, after the p1 spot check on silver facts. No setting was chosen by looking at gold scores.
